# E03-03 宿主私有账本和发送时效候选

本地内部候选，未安装到正式 HTTP 路由、未经过独立技术验收；R6 原包和 E03 已验收权重 33% 不变。

## 实际链路

`openEvidenceHost` 的 `sendLivePacketCandidate` 和 `sendLivePacketPageCandidate` 在服务端维护范围绑定的进程内 Packet 账本。首包与每个独立分页都要求原 workspace ticket 和同一真实 Session，重新读取受权事件及同版 Trip State；调用者提供的任务内容必须与注册时服务端保管的 keyed 摘要一致。翻页按原 Packet 的服务器生成 ID、时刻、Context ID 和预算重建固定快照，比较候选摘要，并只从私有账本判断哪些正文已经发送；客户端不能提供 delivered 清单。

账本长期仅持有随机密钥、keyed 摘要、范围与时效元数据和 delivered 身份摘要，不保存 Packet 原话、Task 明文或明文对象 ID。为每次重建，内部调用方仍须提供原 Task/Focus 数据；当前测试由服务端合成夹具提供，**真实可信任务提供器尚未接入**。原 R6 的 page-request 线协议没有附带 Task 内容，不能把内部参数直接加到客户端协议当作已完成。请求运行期间输入和响应缓冲会暂留内存；当前不能证明数据库或身份服务异常挂起时这些瞬时数据的严格清除时限。

在真实 PG 事务中锁定 Session/成员、工作区、来源和状态，最终检查通过后同步开始 socket 排队；数据库事务提交后不持锁等待网络完成。宿主自身在实际提交后调用 `afterCommit`，随后通过新的受权事务重建并复验，再确认本机 socket `finish` 才更新私有账本。每个包仅允许一个待完成发送，竞争请求失败，可重试；失败、事务不确定或复验失败使该包失效，不能声称未发出的字节已被收回。`finish` 只表示本机传输层交接，不证明客户端收到、理解或持久确认。

同进程持久接受删除、恢复、释放或关闭时清除对应账本；过期账本最多按 Context 截止或五分钟关闭。其他进程完成删除或撤权后，下一次读取/复验会失败并使账本失效；尚未实现跨进程即时失效通知、真实可信旅行生命周期、相关交互续期及完整 E11 自动清理。当前事件以自身记录时间 +180 天作为保守限制，不能宣称已实现相关交互续期。

## 发送前期限

内部受限 E11 数据库函数在授权后返回从数据库时钟计算的剩余时间下界，覆盖当前 Session、事件记录 +180 天、+12 个月、已知旅行结束 +30 天。宿主还按数据库时钟检查 Context 截止，并保守涵盖同版状态内**所有**事实的观察和过期边界，包括未被选中的事实；每个数据库请求从请求前的本机单调时钟与墙钟起算，向下取整并留出至少 1 毫秒余量。在 JSON 编码之后、写头之前以及写头后写正文之前检查两套本机截止，任何一项越界就失败关闭。这可能比实际截止稍早拒绝，是有意的保守技术限制。

真实 PG 反例在最终数据库检查后暂停，分别令 Session 到期、原事件到期及未选中事实开始生效，三个场景均在正文发出前被拒绝；独立 socket 测试还模拟写头期间跨过本机截止，连接关闭且不记账。这些测试不证明进程在最终本机时钟检查与内核排队之间遭任意暂停、机器睡眠且时钟异常、远端数据库时钟突变时有绝对零间隙，也不证明流式逐块输出安全。当前一次性缓冲整个 JSON；序列化和排队仍占用事务时间，没有完整响应大小/耗时 SLA。

删除/撤权若先提交，后续发起的读取失败；读取事务先持锁并启动发送时，删除/撤权提交等待锁释放。把最后有效检查/启动发送视为读取线性化点是对原批准合同的工程解释，仍需技术负责人核准；后到达的网络字节无法收回。若产品要求删除回执后不再收到此前已进入网络的字节，原 Owner 文本未明确这一更强承诺，需要单独裁定。用户身份、跨进程缓存失效、备份/WAL 与实际产品端的交付确认仍不能由本候选推断完成。

## 验证与后续

本地真实 Session/PG/回环 socket 专项验证首包、同包独立页、跨主体/工作区、伪造交付清单、删除后旧包失效、新工作隔离、事务提交后撤权、发送前 Session/事件到期和未选中事实边界。三个相关测试文件共 **62/62 通过**、无跳过；TypeScript、相关文件 lint、155 份原包及 TS/DC 合同校验、Next build 通过。未重复全量测试；本地测试不是远端 CI。代码及 SQL 是候选，未加入正式生产迁移或公开路由；需同一集成版本的独立安全/技术复核、真实任务提供器、R6 HTTP 接线、跨进程失效及 E11 清理完成后才能纳入 E03-03 最终验收。
