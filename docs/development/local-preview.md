# 安途本地网页

macOS 双击根目录的 `启动安途.command`，终端会启动服务，并在浏览器打开 <http://localhost:8080/>。保持该终端打开；按 Ctrl+C 停止。需要 Python 3，不需要先安装 Node、PostgreSQL 或模型密钥。

其他系统或命令行：在工程根目录运行 `python3 scripts/serve-prototype.py`。只启动服务、不打开浏览器时加 `--no-browser`；指定端口时加 `--port 8081`。

## 这次接入的内容

入口直接使用仓库原有的 `prototypes/egypt-trip/index.html`，同时加载它的全部配套 JavaScript、样式、地图及图片。城市与体验内容、关键词回答模板、方案比较、时间轴和交通示例随网页一起可用，无需手动复制进另一份页面。内容仍在原文件维护：

- 城市与基础体验、回答分支：`app.js`。
- 扩展体验和素材来源：`assets/city-experiences.js`、各照片索引及《地图与照片来源.md》。
- 探索规则、方案和假设：`exploration.js`、`skeleton.js`、`hypothesis.js`。
- 交通示例与展示：`transport-fixtures.js`、`transport-connection.js`。

修复后，聊天消息与原有兴趣、旅行条件、行程、草稿一同保存在浏览器的 `antu-f1-f2-v1` 记录中。用户发送时立即保存；模板回答产生时立即保存，刷新后继续显示已有聊天。旧版记录可以继续读取；旧版从未保存过的历史聊天无法补回。浏览器存储不可用或已满时，页面仍显示保存失败提示，不能保证刷新后恢复。

记录按浏览器和网址隔离。`localhost:8080`、`127.0.0.1:8080`、其他端口分别保存；如原来已经有记录，请继续使用原来的浏览器和地址。清除网站数据、使用无痕窗口或换设备不会自动带入旧记录。

## 能力边界

本入口是本地交互原型，服务只监听本机回环地址。聊天使用原有关键词与模板逻辑，交通价格和示例不能当作实时供应商结果；天气请求和外部来源链接需要网络。

浏览器记录尚未同步到 PostgreSQL 或正式 Trip State。原有 Next.js/认证/业务后端代码保留；`npm run dev` 仍启动原后端工程，不能把本入口的可交互页面当成已经完成模型、数据库和前后端联合接线。
