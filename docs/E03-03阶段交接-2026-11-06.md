E11 候选已覆盖原话、幂等回执、任务来源、主动删除与持久清理任务；读取在真实数据库时钟下按可信旅行结束 +30 天、最后相关用户交互 +180 天和单事件 +12 个日历月取最早截止。维护候选可有界扫描、先落不可读标记、再以独立语句重试清除正文；它不是已配置的自动生产调度。旧工作区的内存 Task／Packet 每次使用都回到数据库复验，跨进程即时通知仍缺。

历史证据内部页只接已注册 Task、当前 Session 与工作区；最多 256 个来源、每页 100 条、时间窗 180 天。签名游标绑定当前主体／旅行／工作区／任务、时间窗、持久关联修订、删除修订与固定高水位；来源失效或有未关联事件时失败关闭，不能把空页解读成“用户没有说过”。`HostEvidenceAssociationHead`／`HostEvidenceAssociationLog` 对已验证 link 写入单调、append-only 修订，记载实际 `source_turn_id`；同一有效 Task／事件重复绑定不会新增修订，多 Task 绑定在注册事务中原子提交。日志无原话正文，运行角色无直接表权限。内部显式 `unlinkTaskSourceCandidate` 已增加受信 Session／Task／Turn／来源约束、期望修订 CAS 和操作键重放；事务只移除明确 Task→event 关联并追加 unlink 修订，不删除原事件、不提高工作区删除版本，也不使同一句话中其他 Task 的关联失效。Packet／历史读取按目标 Task 的当前来源重新复验；受影响 Task 及其 Packet 失败关闭，未被否定 Task 仍可继续。如果已保存现场包含受影响 Task，更正返回关联冲突，等待受信替换现场，不能删除整个现场或连带丢弃其他 Task。
