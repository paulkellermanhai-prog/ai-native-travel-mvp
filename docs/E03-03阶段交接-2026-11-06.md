E11 候选已覆盖原话、幂等回执、任务来源、主动删除与持久清理任务；读取在真实数据库时钟下按可信旅行结束 +30 天、最后相关用户交互 +180 天和单事件 +12 个日历月取最早截止。维护候选可有界扫描、先落不可读标记、再以独立语句重试清除正文；它不是已配置的自动生产调度。旧工作区的内存 Task／Packet 每次使用都回到数据库复验，跨进程即时通知仍缺。

历史证据内部页只接已注册 Task、当前 Session 与工作区；最多 256 个来源、每页 100 条、时间窗 180 天。签名游标绑定当前主体／旅行／工作区／任务、时间窗、持久关联修订、删除修订与固定高水位；来源失效或有未关联事件时失败关闭，不能把空页解读成“用户没有说过”。`HostEvidenceAssociationHead`／`HostEvidenceAssociationLog` 对已验证 link 写入单调、append-only 修订，记载实际 `source_turn_id`；同一有效 Task／事件重复绑定不会新增修订，多 Task 绑定在注册事务中原子提交。日志无原话正文，运行角色无直接表权限。内部显式 `unlinkTaskSourceCandidate` 以受信 Session／Task／Turn／来源、期望修订 CAS 和操作键重放撤销指定 Task→event。`supersedeTaskSourceCandidate` 只接受同一 Task 中已经记录并注册的较新事件，持久写入旧→新事件映射后撤下旧的当前来源；旧事件正文和其他 Task 对它的关联不变。Packet／Turn／历史读取按目标 Task 的当前来源重新复验。如果已保存现场包含受影响 Task，更正返回关联冲突，等待受信替换现场，不能删除整个现场或连带丢弃其他 Task。

## 尚未闭合的 E03-03 出口

- `unlink` 仍为内部受信更正候选，已支持**同一事件、多 Task** 的最多 32 项整批事务：任一预期修订、来源或授权失败即全部回滚，整批幂等重放；不同事件、重复 Task、混合重放与新写入拒绝。局部纠错只接明确指定的 Task→event；一句原话内部如何拆成“停留天数”和“节奏偏好”等 Task／证据区段，仍由当前受控解释与独立语义评测证明，宿主不从文字猜映射。未接公开命令或用户可见流程。含受影响 Task 的已保存现场需受信替换后才能更正；跨进程 Task 恢复仍未闭合。
- `supersede` 已实现用户裁决可直接推出的最小映射：同一 Task、一个较旧当前事件、一个较新且已由受信 Turn 注册的替换事件；旧事件保留为历史但不再参与该 Task 的当前读取，其他 Task 不受影响。宿主内部命令明确携带旧／新 event 和 Turn，不修改冻结 DC wire Schema。仍未从裁决推出、因而保持关闭的行为是：跨 Task 改归、多个旧事件对多个新事件的默认配对、从自然语言自动判断被否定区段、以及自动重写已保存现场。
- 未关联事件、未知自由文本来源和缺失关联仍保守返回不完整。当前事件之后的旧证据消费尚未交给真实解释器；多轮语义正确性必须另做埃及场景评测。
