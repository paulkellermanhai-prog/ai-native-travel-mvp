`parseContract` 只证明形状；`parseStateReferences` 再证明本切片的静态引用子集。两者都**不能作为完整业务提交、权限授权或“状态已经可采用”的判断**。类型生成只在内存中把 `$ref` 转为本地定义，不改原 JSON 的字段、枚举、标识或版本。

原 Python `jsonschema` 的基础依赖没有可用的 `date-time` FormatChecker，可能静默略过该检查。本切片在测试环境额外固定 `rfc3339-validator==0.1.4` 与 `six==1.17.0`，并断言 checker 存在；不修改原 requirements 或原校验器。所有示例均来自原合成测试资料，没有网络旅行查询或真实用户数据。
