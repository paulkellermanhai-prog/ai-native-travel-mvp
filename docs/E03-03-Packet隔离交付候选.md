# E03-03 Packet 隔离交付候选

## 阶段目标和现状

原阶段目标是结构化解释输入、真实 Turn/Task/Focus 身份、分层读取与分页交付，以及 E11 先记录后关联、受权读取、保留与删除。E03-02 内部 Context 已验收；当前 03 的 Task 核心、当前 Session/工作区注册、Packet 组装、事件记录和本文件所述交付均为本地候选，尚未完成阶段验收。原包和 E03 已验收规划权重 33% 不变。

本切片新增 `host-runtime/packet-socket-delivery-candidate.ts`：一个进程内私有候选账本，绑定服务端生成的 PacketCandidate，持有随机密钥、候选摘要和对象身份的 keyed 摘要，不保存 Packet 正文、原话或明文对象 ID。首包和分页通过真实 Node `ServerResponse` 输出，只有响应触发 `finish` 且安装方前后复验均成功才记账；并发页串行更新，避免旧账本覆盖；拒绝篡改、清单外对象、首包之前分页及无效候选；撤权复验或快照/期限失效时清除该候选账本。`finish` 仅代表数据交给本机传输层，**不证明客户端收到、阅读或理解**，也不是持久送达回执。

在 `NODE_ENV=test` 的专用测试钩子中，真实 Session、TripMembership、E11 事件、PG 同版 Trip State、注册任务与该 socket 候选在同一事务范围联通。测试向本机 socket 发送包含真实受权读取结果的 Packet；城市对象和用户内容都是测试合成材料。实际应用的 E03 HTTP 路由没有安装此候选，正常运行的宿主不开放该测试钩子。

## 明确阻塞

测试直接展示：响应一旦写出，若随后 Session/来源/期限复验失败，已写出的字节无法收回；当前代码只能清掉账本，不能证明网络交付未泄露。因此 **不得把此候选或测试钩子接到真实用户或生产接口**。候选只由安装方提供复验函数，不能自行证明真实 Session、旅行、工作区、原话来源或删除屏障；这些只能由真正可信宿主完成。当前账本仅存在进程内，不能证明重启后回执或跨服务交付；页测中的快照由测试提供，尚不是单一真实授权状态下的多次独立 HTTP 页请求。

完成 03 所需的最小后续步骤：

1. 技术评审并落实网络交付的线性化与失败语义，特别是权限撤回、删除、期限和断线发生在发送过程中时，哪些字节可安全发送、何时可记账；不能把 postflight 失败后销账当成撤回已发数据。
2. 将候选和账本放进真实宿主私有范围，绑定 Session、旅行、工作区、运行代次和具体 Turn/Task；保证快照、页面内容及账本不可由客户端伪造，关闭/恢复/删除/到期时失效，不能无界留存原话。实现独立页请求的原子合并与失败不记账。
3. 在同一集成 head 使用真实 Session/PG/HTTP 验证首包、不同页并发、跨用户与跨工作区、篡改、会话过期/撤权、源删除/到期、状态变化、网络中断及进程重启；真实发送结果与客户端确认必须区别报告。
4. 补齐 E11 相关交互续期、可信旅行生命周期、自动到期清理和多轮证据读取等 03 出口，核对解释输入协议与 R6 时间精度差异；按原审核链进行技术验收。以上不需要擅自新增产品规则。

## 本次验证

隔离回环 socket 测试覆盖首包、并发分页、不在清单对象、伪造候选、发送前关闭、发送后复验失败、撤权及 Context 过期；发送后复验失败的测试明确承认响应已到达测试客户端。真实 Session/PG/socket 首包专项覆盖真实账号、目标对象、跨用户、撤权和会话过期；未将测试账号或合成城市视作真实供应数据。三个 E03-03 相关测试文件共 **55/55 通过**、无跳过；全仓 lint、TypeScript、Next build 和原包/TS/DC 合同校验通过。未按要求重复完整回归；本结果是本地测试，不是远端 CI 或技术验收。完整的后续多页 Session/PG/HTTP 业务链与正式生产交付尚未完成。
