# E03 工作区能力与 E11 屏障候选

本文件记录 `a6f030e` 的历史切片；后续实现及当前限制见 `E03-保存与来源屏障候选.md`。

本地集成包含 #25 的 a987882399bc42d497802324802c95e3a64b363e（仅追加测试及记录）；本文件、宿主与 SQL 为待审候选，未纳入正式迁移、生产授权或路由。E03-02 原验收不变，E03-03 至 07 不因本候选通过而验收。

同一真实 Session、同一旅行下，宿主为每个工作区生成独立 256 位随机能力；工作区行绑定真实用户、Session、旅行、服务器生成的工作区键与能力。E11 写入、删除和原话读取在数据库事务持锁并核验能力，等待工作区锁后复验授权。权限检查禁止宿主运行身份通过拥有、继承或 SET ROLE 访问现存的 checkpoint 直接表或函数；若有此类权限则拒绝启动。测试专用授权不等于正式授权。

`host_evidence_checkpoint_probe_candidate` 只返回范围和删除版本的真假判断，无正文或版本值；锁顺序为 TS 文档、授权、工作区、旅行生命周期，再复验授权。它不批准独立的 checkpoint 保存或恢复：这些操作必须将能力、全部原话来源、墓碑、期限和读写放在同一事务中，保留锁直到完成；不得先调用 probe、释放锁后再执行正文读写。现有 #25 Session 函数仍允许指定任意工作区，原反例保留，禁止授予宿主运行角色。与其它写路径共同锁序尚须集成复核。

能力当前以随机值存于受限数据库行，仅运行宿主内存持有，代码不向请求返回；数据库所有者可读取，日志及审计系统必须防止记录参数。无跨进程安全重签机制，关闭或释放宿主能力失效，但不删除已持久化证据。生命周期表仍无可信实际写入者，仅测试合成；缺失或过期时读取/probe 失败。尚无 checkpoint 全部来源绑定、事件关联、正文副本清理、备份与跨进程失效证明，故保存/恢复及完整 E11 阶段不可宣称可用。
