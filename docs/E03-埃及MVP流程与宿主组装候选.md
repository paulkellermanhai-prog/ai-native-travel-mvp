# 埃及 MVP 用户流程与 E03 宿主组装候选

依据冻结 PRD §4.1 和 `E03-03-07并行技术放行回执-2026-11-06.md`，本表区分本地工程候选、完整 MVP 所需和仅限隔离测试；不改变产品范围或已验收看板。已验收的 E03-00～02 规划权重仍为 33%，03～07 尚未阶段验收。

| 用户流程 | 原计划及当前事实 | 完整 MVP / 隔离测试边界 |
|---|---|---|
| 说“想去埃及”，浏览地图和体验差异 | PRD-001、005；真实 UI、有限城市数据、地图供应及内容许可/真实性尚未接通 | 完整 MVP 必须提供有限真实覆盖及地图失效替代；合成城市仅可在隔离测试中展示，不能声称实际供应或全埃及覆盖 |
| 文字/操作变成任务，带当前旅行依据继续探索 | E03-03；真实事件和任务身份有内部候选，Packet 核心与已验收只读 Context 存在；尚未有可信解释器、对外 Packet 与送达账本 | 完整 MVP 必须联通真实输入、解释、当前权威状态与交付；本次仅推进同 Session/PG 的内部组装，无模型语义与用户展示 |
| 选择下一步、查询现实条件与费用 | PRD-003、007、009；NAP、可用模型、事实供应商、地图/交通/体验数据、适用范围和新鲜度尚未真实贯通 | 完整 MVP 的被支持数据和权限必须可验证；隔离测试可以使用明确标注的合成事实，数据缺失必须显示未知，不能冒称可执行 |
| 城市组合、比较、修改与明确确认 | PRD-004、006、008 与 E03-04；TS 真正事务和确认底座已有；写桥核心候选尚缺真实 Turn/Packet、用户 Grant、送达和同事务复验 | 完整 MVP 需要对比、修改和确认的真实闭环；不可把合成宿主或静默写入当成确认 |
| 保存现场、重开继续 | E03-05/06；现有候选仅同进程受限保存/内部恢复，删除后封闭；草稿、TS 标识、跨进程和新会话认领未闭合 | 完整 MVP 的保存与恢复须实际可用并阻止旧授权/已删证据复活；隔离测试可只展示受限切片及明确不可恢复状态，不能伪装持久能力 |
| 全链路请求、授权和隐私 | E03-07/E11；HTTP 适配候选未挂生产，真实 HTTP/Session/PG 的整个 Task→Packet→写入→恢复未验证；自动到期清理、备份墓碑及交付屏障未完成 | 对外测试也不能绕过授权或把已删除内容重新交付；生产还需实际生命周期、删除/清理、备份恢复、审计告知和正式 Gate |

埃及具体城市、连接、供应商、交通数据和覆盖水平仍需工程验证；PRD 没有授权将合成样例当真实来源。UI 设计、地图/城市数据、模型与 NAP 不在本 E03 候选中被假定为完成。

## 当前实施：真实宿主的实时 Packet 组装检查

`host-runtime/evidence-host.ts` 新增内部 `inspectLivePacketCandidate`。它绑定已有同进程工作区和真实 Session，用服务端已持有的事件令牌读取已持久事件；调用方重传的 Task/Focus 全量内容须与注册时的服务端密钥摘要相符。任务必须仍是当前已注册版本，原话来源和相关事件均重新验证；在同一 PG 事务锁定的当前 TS 上组装 Context 与 Packet，并验证原 Turn 和最终授权/时效。服务端只返回计数和覆盖枚举，不返回 Packet 正文、授权、原话或送达证明；无 HTTP 路由。完整 Task 不新增常驻文本副本，删除/恢复/工作区释放仍使旧能力失效。

该候选因真实写桥尚未接线，只接受 TS revision 与注册时一致的实时任务，不能替代后续“旧输入基于最新状态重验”的完整功能。返回 `coverage=complete` 只表示此次已选择的对象正文覆盖完整，**不代表已接入真实城市数据、旅行事实充分或模型理解完成**。目标数据和解释任务仍是测试合成输入；没有生产外部数据、解释器、提案确认、私有分页账本、真实用户送达或跨进程恢复。后续须先接可信解释器和私有 Packet/交付宿主，再用同一集成版本验证 Session/PG/HTTP、撤权、删除/到期、分页和安全写桥；不得因为此候选放开对应入口。

验证用例覆盖隔离 PostgreSQL 中合成的埃及/阿斯旺状态、无业务写入、两个真实用户和工作区、篡改输入、更新后的旧任务、撤权、来源到期及删除等待竞争。完整 Vitest 重跑 57 文件、1112/1112 通过、无跳过；全仓 lint、类型检查、Next build 和原包/合同校验通过。这些是本地结果，不是远端 CI 或阶段验收。保留两次问题：初次单独样例漏掉阿斯旺的父对象 `egypt`，补齐后通过；首次完整回归中 Python 参考进程超过 20 秒限时（1111 通过、1 失败），其他检查结束后重跑通过，超时根因未确认。类型检查与 Next build 并行时曾因生成文件不存在失败，构建完成后独立重跑通过。
