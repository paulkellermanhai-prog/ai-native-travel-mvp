CI 保留两个实际运行附件：`e02-03-typescript-scenario-a` 和 `e02-04a-confirmation`（14 天）。后者输出真实 preview/pending/confirm/replay、最终 PG state/history 和 Python 深比较结果，仅含合成数据，不含连接字符串、凭证或个人路径。

## 数据库迁移与最小权限审查

新增 `202610280002_confirmation_capability/migration.sql`，不增加业务表、字段或状态。新增 `public.finalize_trip_confirmation(text,text,jsonb)`：SECURITY DEFINER、固定 `search_path=pg_catalog,public`、对象全限定；PUBLIC 无 EXECUTE。函数只在 trip 行锁下收尾一个明确 Proposal，核对当前文档、最新追加历史、原提交缓存与已插入的确认缓存、Actor namespace、结果/diff/digest/revision、到期等关系，再更新**对应原键的 response**并删除**对应 Proposal**。无动态 SQL、通用 patch 或任意表/列参数。

运行身份只增加该准确签名的 EXECUTE；仍无 Proposal/Idempotency 通用或列级 UPDATE、DELETE、TRUNCATE，无历史改写或 DDL 权限。既有 document 的 snapshot/revision 两列更新权限保持原状；历史仍有追加约束和不可改写触发器。运行 DB 凭据属于可信服务边界，不交给不可信调用者；数据库函数不能替代真实宿主身份系统。

部署角色名称不写死在 Prisma migration。版本化 `scripts/grant-confirmation-runtime.mjs` 只对明确指定、已经存在的非管理/非表 owner、没有上述宽泛 DML 权限的运行身份授予这一 EXECUTE，不创建角色、不放宽其他权限。CI 的 `prepare-storage-tests.mjs` 自动调用同一授权代码。复现使用已安全配置的 MIGRATION_DATABASE_URL 与 TRIP_STATE_RUNTIME_ROLE，凭据不作为命令参数：

```sh
npm exec -- prisma migrate deploy
node --env-file-if-exists=.env scripts/grant-confirmation-runtime.mjs
npm run check
npm run db:check
```

已实际完成：全新空库执行两份迁移；上轮保留的隔离库从 1 份迁移增量升级为 2 份，四张表内容指纹完全不变，原运行身份的函数 EXECUTE=true、缓存 UPDATE/提案 DELETE=false。没有操作生产数据库、修改仓库安全设置或创建收费资源。

本地干净临时副本，Node 24.22.1、npm 11.19.1、PostgreSQL 17.10、Prisma 7.10.1；规格/生成契约、Prisma validate/generate、TypeScript、Lint、**413 项测试 / 10 文件，零跳过**、Build 全部通过。原 360 项测试保留；3 处原“能力未开放”断言随本轮授权更新为 pending 且 state 不变，迁移数量断言更新为两份；没有删除原保护测试；原 257 条批量 Python 对照仅将该项 Vitest 时限与既有 60 秒子进程上限对齐，断言不变。新增 19 项纯规则/Python 对照、34 项真实 PG 确认集成测试。最终 PR 最新 CI 结果以其 Checks 和执行附件为准。

仅当前已审核的 A 命令/状态子集可写；Constraint/Skeleton/ExternalFact 等需要后续机制的状态和未实现命令继续明确能力拒绝。E02-02 的旧合成 Proposal 无本轮展示绑定元数据，不能充当可消费的真实业务提案；未根据摘要或缺字段补造数据。真实宿主 session/身份提供方与 HTTP 仍未接入，当前只有强制宿主授权的内部库，没有公开业务写入路由。

过期或版本失效的 Proposal 和原 pending 缓存依原 Store 保留；原键重放仍返回原缓存，重新提议须用新键。没有擅自增加自动清理或产品拒绝规则。默认宿主与数据库时钟需同步；测试时钟仅在可信测试宿主注入，数据库收尾按历史中本次确认捕获的时刻核验绝对到期，与原 Store 检查一次的语义一致；不因后续 SQL 延迟新增拒绝规则。存储故障不缓存成功；连接中断后的最终结果用同一幂等键恢复，不根据一次响应丢失推断已回滚。
