## 命令能力矩阵与边界

| 路径 | 当前能力 |
| --- | --- |
| create / revise | 原 Schema 的 TripGoal、Preference、Constraint、DestinationEntity、Candidate、Skeleton、OpenIssue；执行 Actor、终态、fixed、有效/已确认骨架及字段白名单守卫；Decision 仅由专用命令生成 |
| transition | 非 ExternalFact 对象的原表转换及必要守卫；confirm/reconsider/resolve/dismiss/revoke 必须专用入口；Skeleton/Decision supersede 不可单独调用 |
| reconsider | User/System，触发引用属于正式条件且结果严格为 true；false/unknown 均拒绝，不自动接受 |
| decide_candidate | accept / retain / reject；旧确认决定 revised，新决定 confirmed/supersedes；有效骨架/住宿承诺冲突仍阻断 |
| withdraw_decision | 原 revoke；采用决定若指向当前根则同事务清根，保留原决定和骨架 |
| preview / submit / confirm / reject / idempotency | 沿用 E02-04A 完整内部通道，以上新命令经过同一宿主授权、语义和 PG 事务；无任意 snapshot/Actor 输入 |
| ExternalFact | 已有对象完整读取、静态验证、三值条件和承诺保护；唯一已移植的写侧派生是原全局日期变化的 applicability 归一化。ingest_fact、check_freshness、事实 supersede/contradict、供应方接入和核验升级不支持，留 E02-04C |
| recalculate / adopt_skeleton / resolve_issue / dismiss_issue | 明确返回 E02_SLICE_UNSUPPORTED；没有计算、假确认、问题已解决或新骨架采用的完成声明。保留在后续 E02 命令清单，由负责人审查安排，不因本次切片而删除 |
| HTTP / 真实身份提供方 / DC / NAP | 未实现；内部库仍强制宿主身份与 trip 授权，真实接入/HTTP/完整端到端属于 E02-05；DC/NAP 不在本轮 |

B/C/G 未调用上述不支持命令，因此其 8 步是完整通过；对既有采用状态的守卫/撤销测试，不能当作 TypeScript 已执行 adopt_skeleton。Schema 仍是唯一正式字段/状态依据，没有为实现方便缩减原始场景或发明规则。

## 工程结果、差异与停止点

本地清洁副本按锁文件 npm ci；Node 24.22.1、npm 11.19.1、Prisma 7.10.1、原 PostgreSQL 17.10 隔离库。`npm run check`：155 来源哈希、20 离线契约/生成类型、Prisma validate/generate、TypeScript、Lint、**509/509 测试 / 14 文件，零跳过**及 Build 全部成功。原 413 项保留；仅将旧整状态能力拒绝断言更新为完整状态执行/无关对象保留的 Python 对照。新增 96 项：BCG 3、条件 44、生命周期 37、真实 PG 12。最终 PR head 的 CI 和执行附件以其 Checks/Actions 为准。

数据库模型、迁移、运行权限、依赖锁文件、业务契约均未改变；本地复用已有测试库并追加独立 trip 测试记录，CI 沿用既有空库测试流程。没有重建原数据库或放宽授权。合成初态导入仍只有原隔离 Synthetic Storage Harness 可用，生产没有该导入能力或公开写入接口。

实现限制：新增条件执行对超出 JS 安全整数区间的整数操作数明确拒绝（INTEGER_REPRESENTATION），避免把舍入结果当作条件成立；没有给原 Schema 新增 maximum。Python 任意精度整数的跨语言条件算术仍未实现，不能据本次小整数场景宣称支持。真实 LLM 抽取、提供方可信度、事实核验/生命周期与所有状态组合穷举均未验证。
