# E11 存储设计与后续接入

本切片交付 `host-interaction-evidence/v1` 内部合同、纯边界函数及真实 Session/TripMembership 隔离测试基础。**没有新增宿主生产表、迁移、HTTP 入口或事件采集服务。** Prisma/SQL 仍为 E02 已有三项迁移；不能把本次权限测试表述为 E11 已持久化。

## E03-03 的事务及迁移计划

| 设施 | 独立数据与约束 | 事务/权限要求 |
| --- | --- | --- |
| 事件与幂等回执 | owner/trip/workspace、服务器 event_id、原文、entry、received/recorded 时间、单调序号、来源、输入摘要与政策版本；范围内幂等键唯一 | 真实 Cookie Session 与 TripMembership 在事务前及事务内重验；服务器生成 ID/时间；正文与回执同一事务，提交后才 durable=true；同键异内容冲突 |
| 关联日志 | link_id、event_id、task_key、link/unlink/supersede、预期/结果关联修订、source_turn_id、关联操作键 | 先事件持久成功，再 DC 注册任务成功，最后原子关联整个任务批次；CAS 与操作幂等；日志追加，不覆盖原话；Task 归属/分支须由 DC 注册器验证 |
| 删除与清理 | 持久 tombstone、删除修订与清理任务；最小审计不存原话、摘要或游标 | 删除标记和清理任务事务提交后才回受理；标记后立即停读；物理失败重试不能回滚成可读；去内容幂等回执不能复活事件 |
| 分页读取 | owner/trip/workspace/task 及固定高水位，关联/保留修订 | 每页当前权限与到期重验；游标签名/不透明随机令牌由适配器实现；修订变化重开查询，不能将缺页解释为用户从未表达 |

计划迁移须使用独立宿主基础设施表，不向 TripStateDocument JSON、TS history、DC 20 Schema 或 Checkpoint 格式 1 注入 E11 字段。E03-03 在实际引入表时必须验证：空库迁移、E02 已迁移库增量升级、重复部署、约束、事务回滚、并发 CAS、最小列权限、禁止正文旁路读取。运行角色不得拥有表/DDL、身份表写入或任意覆盖原文/审计的权限；具体 SQL 与数据库保护须随实现评审，本文不是已部署的安全机制。

`evidenceAuthorization` 复用现有 `sessionHost` 的实际 Cookie 验证和事务内 `authorize_trip_session`；WeakMap 证明不能由 JSON 伪造，且绑定 owner/trip/workspace/task。传入 scope 必须来自宿主已验证状态，**不接受客户端或模型宣称的任务归属**。当前 Task 尚无 E03 持久化服务，任务存在性/归属检查将在注册器接入时实现；本切片只检验不同 scope 不能复用证明。

## 锁定的技术边界

- 内部合同与政策标识：`host-interaction-evidence/v1`、`DC-AC8-PRIVACY-01`；独立错误集合见 `src/server/interaction-evidence/contracts.ts`，不新增 DC 错误枚举。
- 正文 1～16,000 Unicode 码点；客户端输入只允许 entry/text/idempotency_key，owner、Session、event_id、来源及时间均由宿主绑定。形状验证本身不产生可信事件。
- 页大小 1～100，单次查询时间窗至多 180 天，游标最长 15 分钟。它们是有界技术读取参数，不限制获准的原文保留期限；需要更长范围时按有界窗口分页。游标结构检查不等于验签，当前没有客户端 token 接收入口。
- 保留取旅行结束＋30天、最后已核实相关交互＋180天、记录＋12个 UTC 日历月的最早截止；无关联事件以自身 recorded_at 起算。日历月末夹到合法日，例如 2028-02-29 → 2029-02-28。等于截止即拒绝；删除先于物理清理生效。只有经核实相关交互能更新期限输入；普通聊天不更新，生产更新服务留 E03-03。
- 超 12 个月续存暂不开放；备份/审计具体有限周期、告知、删除验证和工程 Gate 缺任一项保持关闭。测试中的 7 天/30 天配置仅为合成测试值，不是新产品隐私裁决。
- 旧原话页的 authority 固定 `historical_evidence_only`，不携带 WriteGrant，不构成本轮 TS 操作授权。读取权限证明和当前写入授权分离。
