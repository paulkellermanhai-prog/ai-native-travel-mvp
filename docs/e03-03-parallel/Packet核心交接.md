## 必须由主工程提供的可信宿主连接

这些函数是**规则核心，不是安全入口**。真实调用者必须：

1. 从真实 Session、当前成员关系、工作区和实际注册器获得并验证 turn/task 归属及合法事件；不可用请求里的字符串或测试桩替代。
2. 使用可信保管的、同主体/旅行/会话绑定的 Packet 候选与不可伪造的服务端账本；禁止将客户端声称已发送的 ID 交给 `recordDelivery` 当事实。仅成功发送后由宿主提交返回的账本更新；失败时不更新，交付不证明阅读或理解。`preparePage.remaining_ids` 是本次成功交付时的候选结果，不是持久回执。
3. 在真实的页操作前、后执行 Session/成员授权、权威快照读取、当前时钟和 Context 复验，并传入各自实际读取的状态。纯函数无法证明这些读取发生的时序、原子性或真实授权；其返回结果不能单独作为 Grant 或写权限。
4. 明确提供可信的恢复输入和保存未确认状态；缺依赖不得用 `false` 或空账本默认放行。重要选择的完整交付要求由 E03-04 写桥按原规则执行，不把此要求扩大到所有命令。
5. 真实 Task 注册器、Packet 服务及共享接口由主工程负责；在缺它们时，本次未接真实 Session/PG/HTTP 的 Packet 服务。E11 删除/到期屏障、生产入口和写桥分别等待其真实依赖。

## 后续增量：原 Turn 一致性与交付反例

`checkPacketTurn` 先复用原 `turn` 合同，检查 Turn ID、原 revision 与 pending.base_revision、Turn 内任务键唯一、Packet Task 的键和全部字段与原 Turn 快照相同，并强制对比从真实注册器取得的可信 pending 完整值（含事件 ID、入口、原文、来源、时间和处理状态）。它只比较宿主提供的值；传入伪造 Turn 仍可能自洽，**不能证明该 Turn 属于当前主体/旅行**。主宿主须从真实注册器按当前 Session/旅行/工作区取原始 Turn、重验当前权限后调用；缺失或不匹配时关闭该连接点。

补充 R6 同状态对照：原参考先计算完整正文和目标对象的实际 UTF-8 字节值，在阈值前/点/后及既有预算逐个真实调用 `assemble`，比较完整对象正文、顺序、覆盖、支持等级及多个页的正文和剩余清单。增加同 revision 跨事实到期的页面及消费拒绝测试；该情况下交付账本不变。另以明确反例证明并发页基于旧账本覆盖会丢失已送记录，并证明：客户端如果能直接提供完整 `deliveredIds` 数组，纯函数会计算为无缺页；所以它既不能作真实送达证明，也不能用作重要操作的授权。准备页返回的预测剩余清单同样不等于已发送。宿主须私有维护账本，发送成功后以原子更新或等价并发控制合并送达集合，不让并发页覆盖彼此；若权限/状态在页前后检查不一致则拒绝并不推进账本。上述要求不能由类型、模拟回调或本次纯函数测试当成已实现。

## 独立审核修正：候选完整性和账本范围

本次增加候选全量内容和 ContextAssembly 的 SHA-256 指纹校验；删除恢复只读/保存未确认警告、改动 pending 或正文会拒绝。**该指纹可被重新计算，不是 MAC、权限证明或不可信请求的认证。** 主工程必须在只对服务端可访问的上下文保管原始候选及校验数据，绑定真实主体、旅行、会话、运行代次和可信 Turn/Task，不能接受客户端自行提供的候选或指纹。

交付账本由裸数组改为 `{packetId, deliveredIds}`，核心拒绝缺失、范围外及跨 Packet ID 复用；同一标识的伪造账本仍可自称全部送达，该数据结构不是凭据。宿主必须在实际发送成功后，以私有账本记录并使用事务/CAS 或等价机制原子合并并发页；发送失败、权限撤回和快照复验失败不可推进。测试覆盖跨包重放、伪造完整清单的已知危险、同一旧账本并发写丢失、候选安全警告删除、来源变更和 revision 不一致。

共享 E03-02 Context 只接受毫秒 `Date`；当微秒到期与实际时间位于同一毫秒时，消费时效可能滞后一个毫秒。该共享问题由主工程处理，本分支未改共享文件；以当前核心不能证明亚毫秒到期安全。尚未真实接通注册器、授权、私有账本与发送事务，所有这些负例须在真实宿主和同一集成 head 再验证。

独立审核修订的 task-core/packet-core 专项 **24/24** 通过；包含对「可重算指纹」及「更改 packetId 伪装账本」的反例，证明两者仅作一致性检查，不能替代服务端私有保管和认证。类型、lint、冻结规格/合同检查和单独构建通过。本机真实 PostgreSQL 测试的先前失败及跳过保留，新的真实 PG 回归以新精确 head 的 CI 为准。
