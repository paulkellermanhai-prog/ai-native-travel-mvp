# E03 宿主记录切片：未接线候选

本文件保留早期切片记录；当前 E03-03 主集成状态与未完成出口见 `docs/E03-03阶段交接-2026-11-06.md`，恢复候选见 `docs/E03-受限恢复安装候选.md`。下文早期测试数字仅代表对应历史切片，不是当前最终测试数。

基于 `16b5d21673a41013c5130ac21f30102771cc400b` 的独立主集成分支。`evidence-event.ts` 将已由服务端取得的主体、Session、工作区和客户端正文整理为事件候选；它只检查形状、生成 ID、复制时间和计算内容摘要，不证明来源、授权或持久化。客户端不能借此自报主体、Session 或工作区。

`evidence-host.ts` 是未接外部入口的内部候选服务：使用真实 Cookie Session、成员关系和事务内 `authorize_trip_session`；工作区由宿主生成，数据库和进程内不可伪造的票据均绑定同一主体、旅行和签发 Session。事件回执只在数据库事务成功返回后标记 durable。删除操作候选在同一事务记录删除标记及清理任务；清理函数保留标记和幂等查找令牌，清除正文、摘要与 Session 引用。客户端幂等键先由服务端使用至少 32 字节的独立秘密和范围键做 HMAC，不向数据库保存明文键；重试依赖秘密稳定保存，不能采用测试随机密钥作为生产运维方案。墓碑有限保留周期及秘密管理仍须生产启用前批准和验证。启动时拒绝对证据表拥有直接权限或所有权的运行角色，包括继承和 SET ROLE 路径。这个工作区票据目前不支持重新登录或跨进程恢复。

`sql/001-evidence-record-candidate.sql` 尚未加入 Prisma 正式迁移链；它撤销 PUBLIC 表、序列及函数权限，不授予运行角色权限。SQL 的记录函数信任获准运行服务提供的事件 ID、到达时间和 HMAC；数据库单独不证明这些参数由真实用户或受信宿主产生，运行身份不能交给不受信调用者。`evidence-host.pg.test.ts` 仅允许已有专用 E02 一次性测试库，测试时由迁移角色临时安装候选 SQL 并授予受限函数权限；仅测试角色可通过服务调用。测试包括真实 Session、并发幂等、交错撤权/过期、越权、删除及回滚清理。无测试库时全部实库项跳过，不能宣称已验证。没有经过真实 PG 和权限审核前不能把 SQL 加入正式迁移或生产配置。

本机已用 PostgreSQL 官方 17.6 源码编译临时实例，源码 SHA-256 为 `e0630a3600aea27511715563259ec2111cd5f4353a4b040e0be827f94cd7a8b0`；仓库脚本在该实例创建随机空测试库与独立受限角色。真实测试第一次为 5 通过、2 失败，两个失败因为测试在持锁事务内读取缓存的活动统计，未观测到等待；改为独立观察连接后重跑为 7/7 通过。该重跑验证当前工作树的记录、会话绑定、删标记及清理切片，不代表全部 E11 或阶段验收。

新增内部 `registerTaskIdentity` 候选：只接受原宿主提交成功后签发的不可克隆回执，在同一受权事务中读取当前 TS 并校验引用、版本与目标；事件正文从受限函数读取，注册表只保留任务种类/分支/进度、来源令牌和 keyed 指纹，不长期保存原话、原始 task_key 或任务证据；task_key 以范围绑定 HMAC 索引，防止它恰好是被删原话时在注册表明文残留。持同 Session、旅行与工作区的有效事件按相同输入重放；相关源失效时失败关闭，无关新任务不受阻。宿主内记录、删除和注册串行；删除清理受影响的回执、来源令牌和指纹，任务身份仅标记缺证。重复记录使用同一重放回执，显式 `disposeWorkspace` 或宿主关闭会释放进程内能力，但工作区和不同事件数目前没有容量上限，须由未来宿主配置及运维约束；JavaScript 不保证堆中字符串物理擦除。跨进程删除时，下次操作依赖数据库重验，尚无通知其他进程主动清理内存的机制。
