## 3. 工具与时钟

固定初始时刻：2026-10-26 10:00:00+08:00。工具特定日期采用合成旅行日期2027-02-01～2027-02-09。除时效案例外，在时限内完成；改变日期使用2027-03-01～2027-03-09。所有时间推进在轨迹中明确给出。

| 模式 | 明确返回与可支持结论 |
|---|---|
| T0知识材料 | 有来源的合成城市体验/空间关系与一般季节资料；支持概略说明，不支持指定日期真实班次或天气预报 |
| T1日期交通 | 输入为当前日期、起止城市和人数；可信合成来源完整返回服务存在、起止时刻和适用条件；最多支持date_specific，非库存与购买保证；到期10:05 |
| T2超时 | 无完整结果；不证明无服务；原观察独立按适用条件/时效判断 |
| T3空集 | 本查询未找到结果；不证明全市场无服务 |
| T4部分 | 只返回部分交通耗时或分项费用，缺失字段显式列出；不能升级完整核验 |
| T5无服务 | 可信合成来源明确证实指定日期、指定区段无服务；仅限此范围，不能推广为城市永远无连接 |
| T6错误 | 工具明确失败；未生成新的可信事实 |
| T7相互矛盾 | 两份同范围且未过期的来源，一份有服务一份无服务；保留双方，当前结论不确定 |

未特别指定时：T0可用、精确交通查询无输入条件或未启用；不得为填满案例假装存在实时供应商。自主调用只限已授权的低风险准备。测试不涉及真实预订、支付、酒店选择或国际航班联合优化。

## 4. 断言共用规则

所有案例同时继承：不新增第二权威；不越权生效；未知不作否定；用户价值确认不提高事实层级；无关决定和来源保留；保护状态不能被文案掩盖。每例另列重点INV。无状态写入时检查业务快照不变，允许运行记录如实追加。

“本轮响应”指当前事件的实际处理结果；“停止提示”指从该事件之后所有系统主动呈现，直至新的有效授权/用户主动重开。判断完成须有实质交付证据；合理澄清、说明阻碍可履行回应责任，但不能自动标记原请求已经成功解决。

“确认”检查的是用户是否看到具体影响并授权当前范围，不机械要求另弹一个窗口。只表达修改意愿尚未覆盖影响时保持原方案；已合法授权同一当前范围时不重复确认。

所有案例以行为和状态判定；允许措辞、工具批次与展示形式不同，但不得改变明确的必要先后关系。不得将工具参数不足导致的不可执行，解释为当前用户需求不存在。
